نظام مديرية أوقاف السويداء - الحزمة الكاملة المحدّثة
========================================================

هذا الملف يحتوي النظام كامل بكل التعديلات لغاية الآن. المحتويات:

1) index.html   ⭐ النظام الحقيقي المربوط بالخادم (هذا اللي تستخدمه فعلياً)
   ------------------------------------------------------
   - تسجيل دخول حقيقي، صلاحيات تُخفي عناصر القائمة تلقائياً حسب دور المستخدم
   - إجبار تغيير كلمة السر عند أول دخول بكلمة سر مؤقتة وضعها مدير النظام
     (حتى مدير النظام نفسه ما بيضل عارف كلمة سر الموظف الفعلية)
   - فلاتر منسدلة تلقائية بكل قسم لكل حقل نوع قائمة (الحالة، الفئة، النوع...)
   - تصدير Excel واستيراد Excel لكل قسم، مع معاينة قبل التنفيذ وتقرير نتائج
     مفصّل بعد الاستيراد (رقم كل سطر فشل والسبب)
   - صلاحيات "تصدير/استيراد" إضافية يمكن منحها لمستخدم مُحدد فوق دوره الوظيفي
   - العملة متوفرة كحقل عند إضافة معاملة مالية أو بند ميزانية
   - رصيد المساجد يعرض تفاصيل كاملة: اسم المسجد وموقعه، وتفصيل كل بند
     تبرعات ورد له وكل بند صُرف عليه (وليس رقماً إجمالياً فقط)
   - الشريط الجانبي ثابت أثناء التمرير (يتحرك المحتوى فقط)، مع إمكانية طيّه
     لعرض ضيق بالأيقونات فقط (تُحفظ الحالة بين الجلسات)

   لا تفتحه مباشرة بدبل كليك — شغّله عبر سيرفر محلي بسيط:
     cd awqaf-system && python -m http.server 8080
  ثم: http://localhost:8080/index.html

2) demo-interface-offline.html
   ------------------------------------------------------
   نسخة تجريبية قديمة بلا خادم ولا حماية — فقط لعرض الشكل بسرعة. لا تُستخدم لبيانات حقيقية.

3) database-schema.sql + backend/
   ------------------------------------------------------
   قاعدة بيانات PostgreSQL كاملة (23 جدولاً) + خادم API (Node.js/Express) حقيقي:
   المساجد، المشاريع، عروض الأسعار، العقود، كشوف المهندسين، أوامر الصرف،
   الحلقات القرآنية، المدارس الشرعية، الأرشيف، الميزانية (بعملة قابلة للاختيار)،
   المعاملات المالية (بعملة قابلة للاختيار)، التنمية الإدارية، المستخدمون
   والصلاحيات (أدوار + صلاحيات إضافية فردية)، الإعدادات، سجل التدقيق الكامل.

   طبقات الحماية: كلمات سر مشفّرة (bcrypt)، JWT بكوكيز httpOnly وتدوير تلقائي،
   RBAC حقيقي على كل مسار، حماية من حقن SQL وCSRF، قفل حساب تلقائي، سجل تدقيق
   كامل، منع نهائي للحذف الفعلي للسجلات المالية والحساسة على مستوى قاعدة
   البيانات نفسها.

   اتبع backend/README.md للتشغيل المحلي، وفيه جدول كامل بكل نقاط النهاية.

4) deploy/
   ------------------------------------------------------
   ملفات جاهزة للنشر المجاني بدون بطاقة ائتمان (Supabase لقاعدة البيانات +
   Back4app Containers للباكيند + GitHub Pages للواجهة):
   - Dockerfile و .dockerignore: يوضعوا داخل مجلد backend/ عندك
   - .gitignore: يمنع رفع .env أو node_modules لـ GitHub بالخطأ
   - DEPLOY_GUIDE.md: دليل كامل خطوة بخطوة بالعربي

⚠️ نقطتان يجب معرفتهما دائماً:

   أولاً: لا يوجد "أمان مطلق 100%" في أي نظام حقيقي. راجع قسم "ما هو مسؤوليتك
   أنت" في backend/README.md قبل أي إطلاق فعلي (HTTPS، جدار حماية، نسخ احتياطي،
   مراجعة أمنية مستقلة).

   ثانياً: كل مرة تُحدَّث فيها database-schema.sql (جداول أو أعمدة جديدة)، لازم
   تُعاد قاعدة بياناتك الفعلية إنشاؤها من الملف المحدّث (drop + recreate أثناء
   مرحلة التطوير الحالية) وإلا ستظهر أخطاء "تعذر تحميل البيانات" بالأقسام
   الجديدة فقط.
